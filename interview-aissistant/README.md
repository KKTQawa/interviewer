# Interview Assistant

面试达人 - 智能AI模拟面试平台前端

## 技术栈

- Vue 3
- Vite
- Pinia (状态管理)
- Vue Router
- Ant Design Vue / Naive UI / Element Plus (UI组件库)
- Axios
- ECharts (图表可视化)

## 项目结构

```
interview-aissistant/
├── src/
│   ├── main.js                # 入口文件
│   ├── App.vue                # 根组件
│   ├── router/                # 路由配置
│   ├── store/                 # Pinia 状态管理
│   ├── views/                 # 页面视图
│   ├── components/            # 业务组件
│   ├── utils/                 # 工具函数
│   └── assets/                # 静态资源
├── public/model/              # 前端模型资源
├── package.json
└── vite.config.js
```

## 运行

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build
```

## 功能特性

- 实时AI模拟面试
- 面试报告生成与分析
- 简历编辑与管理
- 用户社区交流
- 个人资料设置
